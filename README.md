# Customer Segmentation using K-Means

This project segments customers into distinct groups based on Annual Income and Spending Score to help businesses with targeted marketing.

### 🔧 Tech Stack
- Python, Pandas, NumPy
- Matplotlib for Visualization
- Scikit-Learn (KMeans)

### 📈 Process
1. Generated synthetic data of 200 customers
2. Performed EDA
3. Used Elbow Method to find optimal K=5
4. Clustered customers into 5 segments (C0-C4)
5. Created Cluster Profile Table

### 📊 Visuals
- Income vs Spending Scatter Plot
- Elbow Method Curve
- Final Customer Segments Plot

### 💡 Key Insight
Identified groups like High Income - Low Spenders vs Low Income - High Spenders.
